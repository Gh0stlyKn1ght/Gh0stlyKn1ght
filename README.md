## Robotics + Security

A robot is not just code.

It is a stack of interconnected systems:

```text
Application / Autonomy
        ↓
Robot Frameworks
ROS 2 / WPILib / APIs
        ↓
Middleware / Messaging
DDS / NetworkTables / IPC
        ↓
Operating System
Linux / RTOS / Controller Runtime
        ↓
Networking
Ethernet / Wi-Fi / CAN / Serial / RF
        ↓
Embedded Systems
MCUs / Sensors / Motor Controllers / Radios
        ↓
Physical System
Motors / Mechanisms / Power / Environment
```

My work increasingly focuses on understanding and securing the **entire stack**, not just individual applications.

---

## Engineering Philosophy

I prefer systems that are:

- understandable
- reproducible
- observable
- documented
- testable
- secure by design
- usable without depending entirely on cloud services

I am more interested in **architecture and failure modes** than collecting tools for the sake of collecting tools.

The goal is to understand how the pieces interact well enough to build better systems.
